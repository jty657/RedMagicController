# RedMagic Controller

A modern Android controller app for RedMagic 8 Pro Cooler.

## Features

- Bluetooth LE connection to RedMagic 8 Pro cooler
- Fan control (Manual, Smart, Boost modes)
- Per-LED RGB lighting control (16 LEDs)
- Modern Material Design 3 UI

## Building

```bash
./gradlew assembleDebug
```

The APK will be in `app/build/outputs/apk/debug/`

## Download

Latest APK available in GitHub Actions artifacts.
